# Установка каркаса — подробно

## 1. Что ставится

`install.ps1` копирует папку `skeleton/` из этого репозитория в указанную вами папку.
Сам установщик и документация в проект **не попадают**.

| шаг | что делает | проверка после шага |
|---|---|---|
| 0 | зависимости: Node.js 20+, Git; недостающие — по согласию через `winget` | «ok: <путь>» у обеих строк |
| 1 | создаёт папку и копирует `skeleton/**` | файлов столько же, сколько в `skeleton/` |
| 2 | подставляет `{{PROJECT_NAME}}`, дату; собирает `workflow/CONTEXT.md` | `state.json` — валидный JSON, `CONTEXT.md` ≤ 4 КБ |
| 3 | `git init -b main`, первый коммит «каркас агентской системы» | `git status --porcelain` пусто |
| 4 | `node workflow/tools/protocol.mjs check` | «Расхождений нет» |
| 5 | печатает отчёт: куда поставлено, что делать дальше | — |

Продолжить после сбоя: `.\install.ps1 -Path <папка> -From 3` (ранние шаги пропускаются).

## 2. Зависимости

| что | зачем | если нет |
|---|---|---|
| **Node.js ≥ 20** | работает `workflow/tools/protocol.mjs` | установщик предложит `winget install --id OpenJS.NodeJS.LTS -e`; отказ — установка не начинается (без Node протокол мёртв) |
| **Git** | своя история коммитов в новом проекте | предложит `winget install --id Git.Git -e`; при отказе каркас встанет без `.git` (в отчёте будет предупреждение) |
| **winget** | чем ставить недостающее | если нет (старая Windows) — печатаются ссылки: nodejs.org, git-scm.com |
| OpenCode | открыть папку и работать с плагином | не обязателен: папку можно открыть позже |

Флаг **`-InstallDeps`** = «разрешаю установщику ставить недостающее без вопросов».
Без флага установщик спрашивает: `Поставить сейчас? (winget install --id …) [y/N]`.
В авто-режиме (`-Auto -Yes`) без `-InstallDeps` он **ничего не ставит**: печатает команду
и, если зависимость необязательная, продолжает без неё.

## 3. Режимы

- **Пошаговый (по умолчанию)** — план, затем подтверждения перед стартом и перед git.
- **`-Auto`** — план, 5 секунд на отмену, дальше без вопросов.
- **`-Auto -Yes`** — без паузы (скрипты, CI).
- **`-DryRun`** — печатает план и выходит; ничего не создаётся.
- **`-Doctor`** — проверяет Node.js, Git, winget, OpenCode, `skeleton/`, состояние целевой папки.
  Ничего не пишет. Код возврата 1, если чего-то не хватает.

## 4. Защита от неприятностей

- **Непустая папка**: отказ, пока не указан `-Force` (перезаписываются только совпадающие
  по имени файлы; лишние не удаляются).
- **Повторный запуск** в уже установленный проект: нужен `-Force`, иначе отказ.
- **Лог**: `%TEMP%\agent-workflow-install-<дата>-<время>.log`.
- **Прав администратора** установщик не требует; секретов не запрашивает.
- Ставятся только те программы, на установку которых вы ответили «y» (или дали `-InstallDeps`).

## 5. Откат

Удалить созданную папку. Ничего вне папки (кроме, при согласии, установленных Node.js/Git)
установщик не создаёт.

## 6. Частые ошибки

| сообщение | что делать |
|---|---|
| `Node.js: НЕ НАЙДЕН` | `winget install --id OpenJS.NodeJS.LTS -e`, затем новое окно терминала |
| `нужен Node.js >= 20` | обновить Node.js той же командой |
| `Git: НЕ НАЙДЕН` | `winget install --id Git.Git -e` (или разрешить установщику) |
| `winget не найден` | поставить Node.js и Git вручную: nodejs.org (LTS), git-scm.com |
| `папка … не пустая` | другая папка или `-Force` |
| `рядом с install.ps1 нет папки skeleton/` | скачать репозиторий целиком (ZIP), а не один файл |
| `protocol check нашёл расхождения` | список в выводе показывает, что с чем не сходится (обычно ручная правка `TASKS.md`/`state.json`) |
| скрипт не запускается | `powershell -ExecutionPolicy Bypass -File .\install.ps1 -Path <папка>` |

## 7. Как это проверялось перед выпуском

| проверка | результат |
|---|---|
| установка в пустую папку (`-Auto -Yes`) | `protocol check` чистый, `CONTEXT.md` ≈ 2,1 КБ |
| повторная установка в ту же папку | отказ, код 1, файлы целы |
| `-DryRun` | ни одного созданного файла |
| свежий каркас: `next`, `claim 1`, `finish 1` | работают, демо-задача закрывается |
| клон репозитория с GitHub → установка | чисто (тот же путь, что у пользователя) |
| нет Git (`AW_FAKE_MISSING=git`) | предупреждение, каркас встаёт без `.git` |
| нет Git + `-InstallDeps` | вызов `winget install` выполняется, после него повторный поиск |
| нет Node.js | установка останавливается с командой установки |

Для ручной проверки «а если программы нет» есть служебная переменная:
`$env:AW_FAKE_MISSING = "git,node"` — установщик делает вид, что их нет.
