# Промпт для агента — установить каркас на этой машине

Скопируйте весь текст ниже в новый чат агента (OpenCode, Claude Code, Codex — любой с shell).

---

Установи мне каркас системы контроля проекта **agent-workflow** в новую папку.

Репозиторий: `https://github.com/artimiti/agent-workflow.git`
Если git нет — каркас скачивается ZIP: `https://github.com/artimiti/agent-workflow/archive/refs/heads/main.zip`
(распаковать и работать из распакованной папки).

Работай строго по шагам, ничего не выдумывая:

1. **Проверь машину** — ничего не меняя:
   - `node -v` (нужен 20+), `git --version`, есть ли `winget`;
   - если репозиторий уже скачан — скажи куда, второй раз не качай.
2. **Спроси у меня**: папку, куда ставить (полный путь), и название проекта для README.
   Ничего не создавай, пока я не подтвержу.
3. **Подготовь каркас**: `git clone …` во временную папку, а если git нет — предложи скачать ZIP
   в браузере и продолжить из распакованной папки.
4. **Запусти проверку**:
   ```
   .\install.ps1 -Doctor -Path <моя папка>
   ```
   Покажи вывод (что ok, чего нет) и, если чего-то не хватает, назови команду установки.
   **Не устанавливай Node.js/Git молча** — спроси разрешение; с моим согласием повтори
   запуск с флагом `-InstallDeps`.
5. **Покажи план** в режиме сухого прогона:
   ```
   .\install.ps1 -Path <моя папка> -Name "<название>" -DryRun
   ```
   Перескажи план своими словами: что появится, где, что будет с git. Спроси «делать?».
6. **После моего «делай»** — установи:
   ```
   .\install.ps1 -Path <моя папка> -Name "<название>" -Auto -Yes
   ```
   (если я разрешил ставить зависимости — добавь `-InstallDeps`).
7. **Проверь результат** сам, не на слово:
   ```
   cd <моя папка>
   node workflow/tools/protocol.mjs check
   node workflow/tools/protocol.mjs next
   git log --oneline
   ```
   Покажи вывод. Если `check` показал расхождения — разберись и почини до отчёта.
8. **Отчитайся**: путь, имя проекта, что установлено, что показал `check`, что делать дальше
   (открыть папку в OpenCode; первая задача — `claim 1`).

Ограничения:

- Не меняй файлы вне указанной папки и временной папки с каркасом.
- Не трогай мой существующий проект (если такая папка есть — это отдельная история).
- Не удаляй ничего, не делай `git push`, не создавай репозиториев на GitHub.
- Зависимости (Node.js, Git) ставить только по моему явному согласию. Не согласился —
  покажи команду и спроси, продолжать ли без этой зависимости.

## Что означает успех

- `protocol check` → «Расхождений нет»;
- `protocol next` показывает задачу №1 (демо-задача «прочитать AGENTS.md и подогнать каркас»);
- `git log --oneline` показывает один коммит «каркас агентской системы…»;
- в папке есть `AGENTS.md`, `workflow/`, `project/`, `.opencode/plugins/protocol/`.
