## 1. Зачем

Пользователь собирает отчёт по проекту и должен отдать его в Excel/1С. Сейчас данные
видны только на экране — приходится перепечатывать вручную.

## 2. Что должно быть

1. На экране отчёта есть кнопка «Экспорт CSV».
2. Файл содержит те же строки, что видны на экране с учётом выбранных фильтров.
3. Разделитель `;`, кодировка UTF-8 с BOM (Excel открывает без пляски с импортом).
4. Числа — без разделителей разрядов; даты — `дд.мм.гггг`.

## 3. Критерии приёмки

- [ ] Экспорт без фильтров = все строки отчёта (сверено с подсчётом на экране).
- [ ] Экспорт с фильтром по периоду = только строки периода.
- [ ] Файл открывается в Excel без предупреждений о кодировке.
- [ ] Если строк нет — скачивается файл с одной строкой заголовков, без ошибки.

## 4. Чего в этой задаче НЕТ

- Экспорта в XLSX и PDF.
- Отправки файла на почту.
- Настройки набора колонок пользователем.

## 5. Открытые вопросы

- Нужен ли экспорт «всей команды» (сводный) или только по одному проекту? — решает заказчик.
