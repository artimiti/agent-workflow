## Цель

Пользователь выгружает отчёт в CSV с учётом фильтров; результат открывается в Excel без правок.

## Шаги

| шаг | что делаем | задача | готово когда |
|---|---|---|---|
| A | Формирование CSV в сервисе (`Reports::csv()`), разделитель `;`, UTF-8 BOM | №10 | юнит-тест на 3 строки и на пустой отчёт |
| B | Кнопка «Экспорт CSV» на экране отчёта, фильтры пробрасываются | №11 | кнопка видна, скачивается файл с именем `report-<дата>.csv` |
| C | Сверка с экраном: количество строк и сумма совпадают | №12 | ручная сверка + тест «фильтр по периоду» |
| D | Документация: строка в STATUS, запись в LOG, коммит | №13 | `protocol check` без расхождений |

## Критерии готовности модуля

- Все критерии приёмки из спеки выполнены и проверены вручную.
- Тесты покрывают: пустой отчёт, один период, границы периода.
- В `workflow/LOG.md` есть запись с доказательствами (что проверено и как).

## Риски

- Excel на разных локалях ждёт разные разделители → фиксируем `;` и BOM, проверяем на двух машинах.
- Большие отчёты (10 000+ строк) → стриминг, а не сборка в памяти.
