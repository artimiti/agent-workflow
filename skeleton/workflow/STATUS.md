## Активный план

**Активного плана нет.** Планы модулей лежат в `project/modules/<модуль>-…-plan.md`;
активный план объявляется здесь (имя файла + этап), шаги дублируются в `workflow/state.json`
(команда `step <план>` показывает незакрытый шаг). Новый этап выбирается по `project/roadmap.md`
и только по явному «делай» пользователя.

**Машиночитаемый указатель:** `workflow/state.json` (этап, шаги планов, «что дальше») +
`workflow/CONTEXT.md` (бриф ≤ 4 КБ, `node workflow/tools/protocol.mjs context --write`).
Вопросы «какой следующий шаг / что не доделано / какой шаг плана X» отвечаются командой
`next` / `open` / `step`, а не пересказом этого файла; расхождения state ↔ TASKS ↔ LOG ловит `check`.
